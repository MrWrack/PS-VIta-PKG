# VPK Manager Theme Creator (PC)

Windows companion app for creating VPK Manager custom themes.

## Features
- Choose PNG/JPG background
- Automatically crops/resizes to 960x544
- Pick accent, panel, text and highlight colors
- Live preview
- Export theme folder
- Export ZIP
- Export Vita-ready folder structure: ux0/data/vpk_manager/theme/

## Run
Double-click `run_theme_creator.bat`.

## Build EXE
Double-click `build_exe.bat`. The EXE appears under `dist/`.

## Vita destination
Copy the generated files to:
`ux0:/data/vpk_manager/theme/`

Files generated:
- background.png
- theme.ini
- theme.json
